### Added

- One Stookwijzer device per house of Gladys located in the Netherlands: the
  RIVM wood-burning advice of its postcode area (yellow, orange, red) now and
  for the next three 6-hour blocks, the advice in words, the wind speed and
  force, and the air quality index (LKI), read once an hour.
- Scene triggers: code red, end of code red, code red announced for the next
  block.
- Dashboard widget: the advice now and for the next blocks, wind and LKI.
- Feature names, texts and documentation in English, French, German and
  Spanish.
